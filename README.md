# Globex Kids Games

Browser games for Globex Kids, built together with the kids who play them.

## Games

| Folder | Game | Status |
|---|---|---|
| `lunch-game/` | Robot lunchroom imposter game: find the robots faking lunch (name TBD by the kids) | Planning |

## Ground rules for every game here

- **Safe by design:** no free-text chat (preset quick-chat and emotes only), private room codes, host can kick and lock rooms.
- **No personal info:** no accounts, emails or real names. Random nicknames only.
- **No in-game purchases:** anything paid is sold on a parent-facing page, never inside the game.
- **Free assets only if the license allows commercial use:** prefer CC0 (e.g. Kenney.nl) and MIT code. No GPL code, nothing "non-commercial."
- **Each game is one folder with an `index.html`** so it can be hosted for free on GitHub Pages.
